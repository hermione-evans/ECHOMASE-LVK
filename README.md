This repository serves as the supplementary material for our paper: [Wu et al., Phys. Rev. D 113, 124023](https://doi.org/10.1103/l31p-1hfr) ([arXiv:2512.24730](https://arxiv.org/abs/2512.24730)). It contains the source code, analysis pipeline, and summary data required to reproduce the figures and results presented in the paper.
Due to size constraints, we're not able to provide the full posterior files. We may add compressed posterior files to run the code, which gives similar results to the full posterior .


## Repository Structure
The repository is organized to mirror the structure of our paper. Below is a detailed description of the contents:


- `./validation`: Code and data for the methodology validation (Sec. IV).
    - violin_plot.ipynb: Generates violin plots for Figure 1 and Figure 3.

    - echo_waveform.ipynb: Generates the echo waveform illustration in Figure 2.

    - posterior.ipynb: Generates the posterior distributions in Figure 4.

    - PE.csv: Contains the best-fit values for the validation study (used in Table II).

- `./search_results/`: Results from the search in real LVK data (Sec. V).
    - violinplot_background.ipynb: Generates background analysis plots for Figure 5 and Figure 6, and calculates data for Table IV.
    - violinplot_event.ipynb: Generates the posterior distributions for the events in Figure 7.

- `./appendix/`: Supplementary results presented in the Appendix.
    - appendix_figures.ipynb: Generates Figure 8, Figure 9, and Figure 12.
    - violin_app_b.ipynb: Generates the violin plots in Figure 10 and Figure 11.

- `python_files_*`/: Templates of Python scripts used to perform the Bayesian analysis on supercomputing clusters.
- `outdir_*`/: Summary statistics of the posterior samples generated by the analysis.



We invite you to explore these directories and make use of the resources within them to better understand our research and methods.
